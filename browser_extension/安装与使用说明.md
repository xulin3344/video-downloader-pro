1. **彻底突破风控反爬**：
   - 针对如**抖音电脑网页版、Bilibili、各类 CMS 影视站、DPlayer 网页**等强动态反爬站点，插件直接驻留在浏览器内部流量出口，**100% 捕获真实已解密播放的视频直链**，无视任何滑块与风控。
2. **双轨智能嗅探引擎**：
   - **网络层（Network）**：实时捕获 `.mp4`、`.m3u8`、`.flv`、`.webm`、`.ts` 及各类 CDN 视频流，扩展图标实时显示嗅探到的资源数量角标。
   - **DOM 层**：智能扫描并动态监听 `<video>`、`<source>`、DPlayer 播放器容器。
3. **🎯 主视频智能识别与广告自动过滤（全新核心）**：
   - **智能时长计算**：自动解析 M3U8 切片总时长与 MP4 真实播放时长，并在卡片上醒目标出（如 `⏱️ 01:25:30`）。

   - **广告自动屏蔽**：智能过滤常见的短于 60 秒的贴片广告、浮窗推广广告及广告联盟域名，默认开启「仅看主视频」纯净模式，也可随时切回「全部资源」。
4. **内置微型视讯动态演示**：
   - 弹窗卡片内直接集成微型播放器，支持画面预览与声音试听，无需跳出页面即可肉眼确认是否是想要的正片！
5. **内置 M3U8 浏览器端多线程切片合并引擎**：

6. **与桌面版下载器无缝双向秒连**：

## 📖 使用指南

### 1. 嗅探视频
1. 打开任意包含视频的网页（例如抖音、B站、影视网站等）。
2. 在网页上正常播放视频（使播放器向服务器拉取媒体流）。
3. 查看浏览器右上角插件图标：右下角会自动亮起角标数字（如 `1`、`2` 等）。
4. 点击插件图标打开弹窗，即可看到嗅探出的所有视频资源卡片！

### 2. 预览与校验
* 每张卡片均带有微型播放器，可直接点击播放/暂停预览画面，确认是正片还是广告片。

### 3. 下载与导出
* **针对 MP4 / FLV 等直链**：点击「直接下载」，由浏览器直接保存到电脑的“下载”文件夹。
* **针对 M3U8 流媒体**：点击「切片合并下载」，进入前端多线程合并界面，支持选择 4/6/10/16 线程，自动分片下载并合成单一 `.mp4` 文件。
* **协同桌面端**：点击「推送到桌面端」，可直接将任务移交本地桌面下载器进行超高速断点续传。

## ❓ 常见问题 FAQ

* **Q：为什么在某些页面打开插件显示“暂未捕获到视频流”？**
  * **答**：现代网页通常采用“延迟加载”策略，只有当用户点击了播放器、或者视频进入可视区域后才会真正请求视频流。此时只需在网页中播放该视频，或点击插件右上角的「重新嗅探」即可立即抓取。
* **Q：M3U8 切片合并下载会消耗服务器流量或上传数据吗？**
  * **答**：完全不会。切片合并是在您本地浏览器的 JavaScript 内存（Web Worker / ArrayBuffer）中完成的，纯本地运行，不经过任何第三方服务器，绝对安全隐私。
